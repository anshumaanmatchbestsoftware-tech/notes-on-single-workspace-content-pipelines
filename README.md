# notes-on-single-workspace-content-pipelines

A short write-up comparing a multi-tool content pipeline with a single-workspace one, using Xelta AI as the worked example.

## Multi-tool pipeline

Separate apps for image gen, video gen, editing, and web layout. Time lost to exports and version matching.

## Single-workspace pipeline

Xelta AI keeps image/video generation, a text-to-site builder, and editing tools (background removal, voice dubbing, lip sync) together. The builder exports HTML/CSS, React, Next.js, and Vue.

## Structured workflows

Microdrama, Comic Flow, Microcourse, Reel Creator, and AI ad tools for repeatable content.
